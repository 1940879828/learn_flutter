# 06 转场动画实验

## 学习目标

- 理解 `PageRouteBuilder` 如何控制页面进入和退出动画。
- 观察 `SlideTransition`、`FadeTransition`、`ScaleTransition`、`RotationTransition`、`SizeTransition` 等基础转场。
- 使用 `flutter_animate` 把常见 fade、slide、scale、rotate、staggered 写成链式动效，减少重复的 `Tween`、`CurvedAnimation` 和局部 `AnimationController`。
- 通过 Hero、Container Transform、Shared Axis、Fade Through 等案例建立移动端动效手感。

## Web 前端迁移映射

- `flutter_animate` 很像 Web 里的 Framer Motion / CSS transition 工具层：它负责把常见动效声明成“这个 Widget 怎么进场”，而不是让你每次手写时间轴。
- `PageRouteBuilder` 仍然相当于“路由层 transition hook”：页面 push / pop 的进度来自 route animation，`flutter_animate` 只是把这个进度绑定到更易读的视觉效果链上。
- `AnimationController` 适合精细控制时间轴、暂停、倒放、物理模拟；普通进场、错峰、按钮反馈优先用 `flutter_animate`，代码更接近产品意图。

## 本章练习文件

- `lib/chapter_06/transition_lab_page.dart`：转场动画实验室。

## 代码观察

- 页面转场：`_animateRoute` 用 `AnimatedBuilder` 读取 route 的 `Animation<double>`，再把进度传给 `child.animate(value: progress, autoPlay: false)`，所以 push / pop 仍由 Navigator 控制。
- 基础动效：Slide、Fade、Scale、Rotation、Shared Axis Z、Fade Through 现在使用 `.slideX()`、`.fadeIn()`、`.scale()`、`.rotate()` 链式表达。
- Staggered：原来的 `StatefulWidget + AnimationController + Interval` 改成 `items.toList().animate(interval: 120.ms)`，更适合教学里观察“列表逐个出现”的意图。
- 同页动效：`AnimatedContainer` 继续演示隐式属性动画，外层用 `flutter_animate` 增加一次轻微 scale 反馈，说明两者可以组合。
