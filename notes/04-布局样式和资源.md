## Web 前端迁移映射

- CSS flexbox 可迁移到 `Row`、`Column`、`Expanded`、`Flexible`。
- CSS grid 可部分迁移到 `GridView`、`SliverGrid`、第三方瀑布流组件。
- `position: absolute` 类似 `Stack` + `Positioned`。
- margin/padding 不靠 CSS 属性，而靠 `Padding`、`Container`、`SizedBox` 等 Widget。
- 资源不是 public folder 直接引用，而要在 `pubspec.yaml` 中声明。

## QA 问答

### Q1：请解释 Flutter 的约束传递模型
`parent` 先下发约束，`child` 告诉 parent 自己尺寸，再由 parent 决定位置。面试里这点非常常见，也是理解 `Expanded`、`Flexible`、`Expanded` 的关键。

### Q2：`Column` 下直接放可滚动列表为什么会报错？
`Column` 想要给子组件无穷高，而滚动视图通常要求收敛高度。应通过 `Expanded`、`Flexible` 或固定高度容器约束，避免布局约束冲突。

### Q3：`Flexible` 和 `Expanded` 的区别是什么？
两者都在 `Flex` 里按比例分配空间，`Expanded` 是 `Flexible(fit: FlexFit.tight)` 的简化语法，通常更“吃满可用空间”。

### Q4：资源在 Flutter 里为什么不能直接像 web 一样随便引用？
Flutter 需要在 `pubspec.yaml` 显式声明资源，否则构建时不会打包进去；这是工程化和体积控制的关键环节，也常在面试中作为基础问题出现。

### Q5：`SafeArea` 和 `MediaQuery` 关系是什么？
`SafeArea` 帮你避开刘海/系统栏区域，`MediaQuery` 提供尺寸和安全区数据。两者结合能让 UI 在不同机型上更稳定。
