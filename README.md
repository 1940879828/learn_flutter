## flutter 常用命令

```
// 检查设备
fvm flutter devices

// 运行到默认设备
fvm flutter run

// 运行到指定设备
fvm flutter run -d <device_id>

// 运行起来后，终端里可以按
r   热重载 Hot reload
R   热重启 Hot restart
q   退出运行
```
