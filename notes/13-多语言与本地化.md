# 13 多语言与本地化

## 学习目标

- 理解 Flutter 多语言的基本链路：locale、key、占位符、fallback、生成文件。
- 能解释 `.arb`、`flutter gen-l10n`、`localizationsDelegates`、`supportedLocales` 的分工。
- 为接手 SpellAI 的 `lib/l10n/`、登录页文案、多语言按钮和生成文件打基础。

## Web 前端迁移映射

- Vue i18n / next-intl 的 message key，对应 Flutter `.arb` 中的 key。
- `t('key', {name})` 对应 `L.of(context).someKey(name)` 或生成 getter/method。
- Web 中的 locale switcher，对应 Flutter `MaterialApp.locale` 和系统 locale。
- 构建期生成类型安全访问器，对应 Flutter 的 `gen-l10n`。

## 核心概念清单

- locale 与 supported locales
- `.arb` 源文件
- `@@locale`
- message key 与 description
- placeholder / 插值
- fallback locale
- `flutter gen-l10n`
- 不手改生成文件

## QA 问答

### Q1：为什么学习 demo 先手写字典，不直接接 gen-l10n？
为了先看清 key、占位符和 fallback 的本质。真实项目必须用 `.arb` 和生成代码保证类型安全。

### Q2：新增一个登录按钮文案要改哪里？
先改所有目标语言的 `.arb` 源文件，再跑 `fvm flutter gen-l10n`，最后在 UI 中使用生成的 `L.of(context).xxx`。

### Q3：为什么不能只改英文？
SpellAI 是多语言产品，只改英文会造成其他语言缺 key、fallback 不一致或生成失败。
