## QA 问答

### Q1：`Future` 和 `Stream` 的边界是什么？
`Future` 表示一次性结果，`Stream` 表示持续事件流。前者一次成功/失败，后者可持续更新。面试里常考 async 数据模型如何选择。

### Q2：Dio 的拦截器一般做哪些事？
常见是注入 token、统一错误码处理、统一日志、重试策略、超时与缓存策略。它对应 Web 里 interceptor/middleware 的职责。

### Q3：`Repository` 层为什么重要？
它把页面和网络细节解耦，形成“调用协议稳定、实现可替换”的边界。面试常问这个层能带来哪些可测性和维护收益。

### Q4：出现接口报错时，UI 与业务层怎么协作？
网络层产出标准化错误模型，业务层决定是否重试/降级，UI 决定展示内容与文案。不要把所有错误都抛给 UI 做业务判断。

### Q5：生成 JSON 模型为什么要自动化？
减少手写转换错误，保证类型与字段一致，并支持重构时更快发现不匹配，尤其在模型字段频繁变化的项目里很关键。
