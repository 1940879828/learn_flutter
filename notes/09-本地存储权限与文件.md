# 09 本地存储、权限与文件

## 学习目标

- 理解移动端文件、缓存、相册、权限和平台差异。
- 掌握常见本地存储：shared_preferences、sqflite、文件目录。
- 为目标项目的图库保存、缓存和下载能力打基础。

## Web 前端迁移映射

- localStorage 类似 `shared_preferences`，但移动端有平台生命周期和备份策略。
- IndexedDB/SQLite 的结构化存储心智可迁移到 `sqflite`。
- Web File/Blob/Cache API 的一部分心智可迁移到 Dart `File`、缓存目录、下载管理。
- 浏览器权限提示和移动端系统权限类似，但 iOS/Android 配置文件更关键。

## QA 问答

### Q1：`shared_preferences` 和 `sqflite` 分别适合什么场景？
`shared_preferences` 适合轻量键值配置（例如布尔、字符串、上次提示状态）；`sqflite` 适合结构化数据和查询需求（历史记录、草稿、分页）。

### Q2：移动端权限请求为什么不能只在启动时一次性弹？
更好的体验是按需请求，用户更愿意在场景中授权。面试里经常问最小权限原则和平台审核风险。

### Q3：`iOS limited` 语义意味着什么？
iOS 有时返回“部分照片访问”；应用必须处理“已授权但受限”的状态，不能默认等同于全部授权。

### Q4：文件路径为什么会在不同设备/平台不一样？
Android 与 iOS 沙箱目录、缓存目录、外部存储策略不同，路径写死会导致问题。要通过 `path_provider` 获取标准目录。

### Q5：保存媒体到相册通常有哪些失败点？
常见是权限未授权、目录不存在、重复写入、文件损坏、系统策略限制，需把每个失败分支给出清晰提示。
