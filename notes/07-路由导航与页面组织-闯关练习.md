# 07 路由导航与页面组织 - 闯关练习

这份练习让你不看最终答案，也能从零敲出一个 `go_router` 多页面小应用。

## 规则

- 一关只练一个路由判断点。
- UI 保持简单，能观察路由行为即可。
- 所有练习代码优先放在 `lib/chapter_07/`。

## 第 1 关：建立路由表

- 新建路由常量类 `LearningRoutes`。
- 声明 `/` 和 `/chapter-07/routes`。
- 新建 `GoRouter`。
- 把 `MaterialApp` 改成 `MaterialApp.router`。

完成标准：首页能跳到 07 实验室。

## 第 2 关：path 参数

- 新增 `/chapter-07/tasks/:taskId`。
- 在详情页读取 `state.pathParameters['taskId']`。
- 页面显示 `taskId`。

完成标准：点击 `task-101` 能看到详情页显示同一个 id。

## 第 3 关：query 参数

- 新增搜索页 `/chapter-07/search?keyword=riverpod`。
- 页面读取并显示 `keyword`。
- 输入新关键字后用 `context.go(...)` 更新 query。

完成标准：URL 里的 keyword 变化后，页面文本也同步变化。

## 第 4 关：extra

- 列表页点击任务时，把完整 `RouteLabTask` 作为 extra 传给详情页。
- 详情页同时展示 path id 和 extra 是否存在。

完成标准：列表进入详情时 extra 存在；redirect 回来时也能靠 path id 展示。

## 第 5 关：返回值

- 新增创建页 `/chapter-07/create`。
- 列表页 `await context.push<RouteLabTaskDraft>(...)`。
- 创建页提交时 `context.pop(RouteLabTaskDraft(...))`。

完成标准：创建页返回后，列表追加一条新任务。

## 第 6 关：redirect

- 新建 `RouteLabSession` 保存假登录状态。
- 未登录访问详情页时，redirect 到 `/chapter-07/login?from=原地址`。
- 登录后用 `context.pushReplacement(from)` 回到 `from`，把登录页从栈里替换掉。

完成标准：未登录点详情先到登录页；登录后回到原详情页；在详情页系统返回能回到 07 路由实验室，而不是退出 App。
