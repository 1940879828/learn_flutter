# 07 路由、导航与页面组织

## 学习目标

- 能从零写一个 `go_router` 多页面练习。
- 理解 Flutter 返回栈和 Web history 的差别。
- 掌握 path、query、extra、页面返回值和 redirect 的使用边界。
- 能把本章练习映射到 `flutter-spell-ai` 的 `PageKeys`、`Pages.toXxx` 和路由表。

## Web 前端迁移映射

- Next/Nuxt 的文件路由默认由目录生成；Flutter 项目通常要显式声明路由表。
- Web 里 URL 常常是页面状态的唯一入口；Flutter 里还要考虑移动端返回栈、页面对象生命周期和转场。
- path 参数类似 `/posts/[id]`，适合表达资源身份。
- query 参数类似 `?tab=notes&keyword=riverpod`，适合表达筛选、搜索、tab 等可选状态。
- `extra` 类似一次跳转时顺手传给下个页面的内存对象，不等于可恢复的 URL 状态。
- redirect 类似 route middleware / navigation guard，常用于登录态、初始化态和权限态。

## go_router 跳转方式完整对照表

| 方法 | 类型 | 栈变化 | 适合场景 | 使用频率 |
| --- | --- | --- | --- | --- |
| `context.push<T>(path)` | 入栈 | 在当前栈顶压入新页面，下面页面保留 | 列表进详情、打开创建页、进入选择器，并等待 `pop(result)` | 高 |
| `context.pushNamed<T>(name, ...)` | 命名入栈 | 与 `push` 一样，只是用 route name 生成 location | 大项目集中管理路由名、path 参数较多、避免手拼字符串 | 中 |
| `context.go(path)` | 切换 location | 切到目标 location，可能重建一组新路由栈 | 搜索条件、tab、首页模块切换、deep link 落点 | 高 |
| `context.goNamed(name, ...)` | 命名切换 | 与 `go` 一样，只是用 route name 生成 location | 目标项目这类有 `PageKeys` / route name 的代码 | 中 |
| `context.pushReplacement(path)` | 替换栈顶 | 用新页面替换当前栈顶，保留下层历史页面 | 登录、验证、裁剪、一次性配置完成后进入目标页，并跳过中间页 | 中 |
| `context.pushReplacementNamed(name, ...)` | 命名替换栈顶 | 与 `pushReplacement` 一样，只是用 route name 生成 location | 大项目里的登录后回跳、支付完成页替换当前流程页 | 低 |
| `context.replace(path)` | 原地替换 | 替换当前栈顶，但复用 page key，尽量保留页面状态且不跑普通入栈动画 | 同一个页面形态下改 id、改 location，或底层路由状态同步 | 低 |
| `context.replaceNamed(name, ...)` | 命名原地替换 | 与 `replace` 一样，只是用 route name 生成 location | 大项目里命名路由版的原地替换 | 低 |
| `context.pop()` | 出栈 | 弹出当前页面，回到上一层 | 关闭详情页、取消创建、关闭弹窗 | 高 |
| `context.pop(result)` | 带结果出栈 | 弹出当前页面，并把结果交给上一页等待中的 `push<T>()` | 创建完成、图片选择、裁剪完成、确认弹窗 | 高 |
| `context.canPop()` | 栈判断 | 不改变栈，只判断是否还有上一页 | 自定义 Back/Home 按钮兜底，避免系统返回直接退出 App | 中 |
| `context.namedLocation(name, ...)` | 生成路径 | 不跳转，只把 name + 参数转换成 location 字符串 | redirect 里生成目标 URL，或先拼好 location 再决定 `go/push` | 低 |
| `GoRouter.of(context).xxx(...)` | Router 实例调用 | 与上面对应的 `context.xxx` 语义相同 | 封装工具类、没有直接使用 extension 风格时 | 低 |

先掌握 `push`、`go`、`pushReplacement`、`pop(result)` 就够写大多数业务；其他方法主要是命名路由、状态保留、兜底返回和封装场景。

## 不常用但要认识的栈操作

| 方法 / 能力 | 来源 | 做什么 | 适合场景 | 注意点 |
| --- | --- | --- | --- | --- |
| `Navigator.of(context).push(route)` | Flutter 原生 Navigator | 手动压入一个 `Route` 对象 | 自定义 `PageRouteBuilder`、教学演示转场、局部 Navigator | 在 `go_router` App 里不要随意混用全局页面跳转 |
| `Navigator.of(context).pushReplacement(route)` | Flutter 原生 Navigator | 用新 `Route` 替换当前原生栈顶 | 不经过 `go_router` 的局部流程页替换 | 和 URL / deep link 同步能力弱 |
| `Navigator.of(context).pushAndRemoveUntil(route, predicate)` | Flutter 原生 Navigator | 压入新页面，并按条件清理旧页面 | 登出后清空业务栈、引导流完成后清空中间页 | 力度很大；`go_router` 项目优先考虑 `go` 或集中封装 |
| `Navigator.of(context).popUntil(predicate)` | Flutter 原生 Navigator | 连续出栈直到满足条件的页面 | 从深层流程直接回到某个原生页面 | predicate 依赖 route name 时要保证每页有稳定 name |
| `Navigator.of(context).maybePop(result)` | Flutter 原生 Navigator | 如果能返回就返回，不能返回就不做或交给系统处理 | 自定义返回按钮、弹窗关闭兜底 | 更偏局部 Navigator；本章优先用 `context.canPop()` + `context.pop()` |
| `Router.neglect(context, () { ... })` | Flutter Router | 执行跳转但不写入浏览器 history | Flutter Web 里更新临时 location 但不希望浏览器后退回去 | 移动端学习阶段很少用 |
| `GoRouter.of(context).restore(matchList)` | go_router 底层能力 | 恢复一组路由匹配结果 | 状态恢复、路由框架内部流程 | 普通页面代码基本不要直接调用 |
| `GoRouter.of(context).refresh()` | go_router 底层能力 | 重新触发路由刷新和 redirect 判断 | 登录态、权限态、初始化态变化后刷新路由判断 | 不负责跳转，只是让路由重新计算 |
| `context.popUntil(routeName)` | `flutter-spell-ai` 项目封装 | 按页面名连续返回到目标页 | 生成结果页、支付/登录等深层流程回到 Home 或项目页 | 不是 go_router 标准 API，依赖项目自己的 observer 栈记录 |
| `context.popExpression((pageName) => ...)` | `flutter-spell-ai` 项目封装 | 按自定义条件连续返回 | 目标页不是固定一个 name，而是一组可能页面 | 读目标项目时要先看 `navigator_observer.dart` 的页面栈记录逻辑 |
| `ShellRoute` / 嵌套 `Navigator` | go_router 路由结构 | 给 Tab、底部导航、模块区创建独立子栈 | 首页多 tab，每个 tab 保留自己的详情返回栈 | 它是栈结构设计，不是按钮点击时调用的方法 |

## 最小练习

本章最终练习覆盖一条完整路由链：

1. 首页通过 `/chapter-07/routes` 进入路由实验室。
2. 列表页展示任务和登录状态。
3. 未登录点击详情页，redirect 到 `/chapter-07/login?from=...`。
4. 登录后用 `pushReplacement` 把登录页替换成 `/chapter-07/tasks/:taskId?tab=notes`。
5. 详情页展示 path 参数、query 参数和 `extra` 是否存在。
6. 创建页通过 `context.pop(RouteLabTaskDraft(...))` 把结果交回列表页。
7. 搜索页通过 query 参数展示和更新搜索词。
